# Edu Ignite

Crie uma landing page de um SaaS de Edutech.
Estilo tecnológico, com movimentos, usando pricipalmente o funco escuro (preto e variações) e desques com a cor vermelha, fontes sem serifa.
Utilize mockups e foque em demonstrar benefícios da plataforma
